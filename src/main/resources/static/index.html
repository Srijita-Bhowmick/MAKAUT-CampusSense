BS-M101 4 Credits

Mathematics 1A (Calculus & Linear Algebra)

Evolutes, definite integrals, multivariable extrema, Cayley-Hamilton theorem, and vector spaces.

Unit 1: Calculus Unit 2: Multivariable Unit 3: Matrices Unit 4: Vector Spaces
BS-PH101 4 Credits

Physics (Optics & Quantum Mechanics)

Newton's rings, Fraunhofer diffraction, Schrödinger wave equation, Ruby lasers, and Maxwell's equations.

Unit 1: Wave Optics Unit 2: Quantum Unit 3: Lasers Unit 4: Electromagnetism
ES-EE101 4 Credits

Basic Electrical Engineering

Kirchhoff's laws, Thévenin's & Norton's theorems, AC series resonance, single phase transformers, and induction motors.

Unit 1: DC Circuits Unit 2: AC Circuits Unit 3: Transformers Unit 4: Machines
ES-CS101 4 Credits

Programming for Problem Solving (C)

Algorithms, conditionals, loops, multidimensional arrays, pointer arithmetic, dynamic allocation, and recursion.

Unit 1: Intro to C Unit 2: Conditionals Unit 3: Arrays Unit 4: Functions Unit 5: Pointers
PCC-CS501 3 Credits

Operating Systems (CSE Sem 5)

Processes, CPU scheduling, Banker's deadlock avoidance, semaphores, paging, LRU page replacement, and file systems.

Unit 1: Intro Unit 2: Processes Unit 3: Deadlocks Unit 4: Memory
PCC-CS502 3 Credits

Database Management Systems

ER modeling, relational algebra, SQL, normal forms (1NF to BCNF), ACID transactions, and 2-phase locking protocol.

Unit 1: ER Model Unit 2: SQL Unit 3: Normalization Unit 4: Transactions
